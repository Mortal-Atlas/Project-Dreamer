# Phase II speech, audition and vocal dependencies

Reviewed November 26, 2026. Revision prefixes below identify the candidate sources reviewed. No source, weight, voice, recording or native package from these candidates is included in the implementation. Licenses for code, weights and individual voices or datasets have separate scopes. A permissive model card is insufficient to establish permission to redistribute an arbitrary voice or reference recording.

Avoid distributing as an embedded library without an approved license/packaging decision. [Praat license and downloads](https://www.fon.hum.uva.nl/praat/) · [Parselmouth](https://github.com/YannickJadoul/Parselmouth/tree/e115ffddb213d680e24000a2171e83ccf6ed9c93) |

Use fixed texts, unfamiliar word forms and independently licensed reference recordings. Benchmark CPU first and record cold start, warm real-time factor, peak RAM/VRAM, output rate and segment failures. Have blinded listeners score naturalness, pronunciation and expressiveness separately. Compare F0, duration and accent under matched conditions. Inspect release terms separately from measured quality. Full TTS model execution and human listening remain pending. The initial round used the lightweight physical instrument in a scratch environment and installed no runtime framework.
