# Research integration and licensing

Source review dated November 26, 2026. This assessment uses author publications, project documentation, and repository terms. Demonstration claims from project maintainers are identified below. External stacks were assessed from source and documentation. The first room experiment can use the existing C# kernel and Unity view.

## Curiosity, continuity and developmental benchmarks

- Intelligent Adaptive Curiosity and learning-progress theory prioritize improving predictions in parts of the environment where learning is feasible. The first experiment can measure prequential loss by action and context, with a noisy object and a learnable object offered side by side. Equalize observation opportunities and test how prior exposure changes selection. [IAC paper](https://adapt.informatik.hu-berlin.de/pub/papers/ims.pdf)
- ICM adds an action-conditioned prediction error and RND adds a fixed random target. Both are useful comparisons for scarce rewards. Implement a raw prediction-error comparator first, then add RND or ICM if the room gives the comparison enough observations and budget. [ICM paper](https://proceedings.mlr.press/v70/pathak17a.html) · [RND paper and code](https://github.com/openai/random-network-distillation)
- Active inference distinguishes expected information gain from preferred outcomes. Go-Explore motivates revisiting unresolved contexts, while POET and developmental curriculum work suggest varying task difficulty. For later stages, measure whether tutored practice transfers to unseen cases after assistance is withdrawn. [Epistemic value](https://doi.org/10.1080/17588928.2015.1020053) · [Go-Explore](https://doi.org/10.1038/s41586-020-03157-9) · [POET](https://arxiv.org/abs/1901.01753) · [Curriculum experiments](https://proceedings.mlr.press/v100/portelas20a.html)
- Read SEDRo's nonverbal assessment designs and VECA's sensor/action contracts alongside iCub's embodied memory studies. First test repeated object interaction and transfer. Later use distinct tasks for object permanence, joint attention, imitation, handwriting and cooperative judgment. [SEDRo](https://arxiv.org/abs/2009.01810) · [VECA](https://ojs.aaai.org/index.php/AAAI/article/view/19877) · [iCub memory](https://doi.org/10.1109/TAMD.2014.2307342)

The project scripts directly use the Unity runtime, input, uGUI, render-pipeline and Burst/Collections APIs. [Unity licenses](https://unity.com/legal/licenses/unity-companion-license) · [Package manifest](../Packages/manifest.json)
- Coplay Unity MCP is MIT at the pinned lockfile revision and currently resolves from `#main` in the manifest. Record the resolved revision when repeating editor measurements. Its editor tooling remains installed. [Pinned license](https://github.com/CoplayDev/unity-mcp/blob/81542a7e86292b5c4c21b1782c5af23b567f45ce/LICENSE) · [Package lock](../Packages/packages-lock.json)

The offline sidecar declares `brian2>=2.5.0` and `numpy>=1.24`; NumPy uses BSD-3-Clause. Pin exact versions with any new recorded stimulus. GameCI and GitHub Actions are build-time tooling. [Test dependencies](../dotnet/DreamMachine.Core.Tests/DreamMachine.Core.Tests.csproj) · [NumPy license](https://github.com/numpy/numpy/blob/main/LICENSE.txt) · [Android workflow](../.github/workflows/android-apk.yml)

For data, document attribution, checksum, source release and selected fields. These checks apply to each concrete version, since public access and redistribution terms can differ.
