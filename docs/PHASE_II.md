# Phase II developmental experiments

## Latch-room audit

The original latch pilot and its published CSV protocol remain available through `--room`. Its learner holds independent effect counts and fast and slow prediction-loss averages for every action/object pair. Curiosity combines decaying novelty, observed outcome consistency, and the fast/slow loss difference. The controls choose uniformly. The learner sees authored object labels and coordinates, an explicit Press demonstration and its effect, and its own contact and resulting feedback. The two-action rule and sampled noise live in the environment. The teacher's Press label provides a recognized action directly. The learner updates its own counts from the demonstration and its interactions. It acquires no new actuator or movement reconstruction skill in that fixture.

The child uses authored one-dimensional approach and contact. The effect follows the seeded rule. Events save direct attempts to an append-only encounter list. At night the code retrieves the latest failed latch action, selects the only other action, and links the two records. The next day attempts the alternative. No learned state from the teacher enters the child. Local prediction state persists during a run. The pilot has no independent checkpoint or across-run training.

The opportunity to solve a binary rule with one demonstration and nine investigations explains the ceiling. A failed action implies the only alternative, and the moved latch uses the same rule after the first test updates the model. All 32 seeds passed both probes in each condition. The curiosity run sampled the noise panel 145 times versus 143 for the random control. [Original protocol and results](EXPERIMENTAL_PROTOCOLS.md#latch-room-pilot)

## Discovery Room

`DiscoveryRoom` is an opt-in two-stage experimental fixture with two visible control IDs. Each interaction exposes two cue bits and accepts two switch movements, one per stage. One control emits a signal only when both movements satisfy its seeded rule. The other emits an independent fair signal. Both use the same action and feedback representation. The rule and noise assignment are private to the environment during exploration. The learner's finite hypothesis family contains the 16 possible two-stage rules and one fair-noise model for *each* control. The family supplies a strong prior about how the world could work. Within this family, posterior weights update only from feedback. Curiosity selects by expected information gain in bits, computed as outcome entropy minus the noise model's posterior mass. A matched random control samples the same choices uniformly. An unresolved question has stable control identity, observed tick, hypothesis probabilities, and append-only attempts. For a hypothesis, the cue, attempted movement and response determine support or contradiction. The question reports confidence and a provisional 0.9 resolution threshold. Questions persist across the simulated night and have an in-memory lifetime.

Reflection proposes one counterfactual from a failed personal attempt, ranked by expected information gain. The second day tests it when the same cue is visible. At most one matched opportunity is reassigned. The rehearsal carries an evidence ID and performs no sensory update. All policies advance the same 0.05-second ticks, use equal action budgets and get the same cue sequence and environmental noise draws. At the end of day two, an evaluator identifies the target control and asks for a best movement in a familiar cue and in a cue pair held out from both training days. Probe outcomes are scored without updating the learner. Transfer is a test of recombining already visible component cues in the supported model family.

```sh
dotnet run --project dotnet/DreamMachine.Cli -c Release -- --discover --start-seed 1001 --seeds 64 --attempts-per-day 6 --out ExperimentOutput/discovery
```

Use 6, 12 and 18 waking attempts per day to expose budget sensitivity. The development check used seeds 1–64 and 18 attempts. The recorded comparison uses seeds 1001–1064 and reports all three budgets. `discovery_attempts.csv` includes pre-feedback probability, expected information, effect and the source attempt for any replay-directed action. `discovery_summary.csv` includes noise allocation, first unlock tick if discovered, Brier loss, unresolved or resolved questions, and both unaided probe outcomes. First unlock can occur by chance, so it is separate from inference quality and probe success. See [measurements](PHASE_II_RESULTS.md).

This instrument abstracts perception to authored cues and manipulation to two ordered switch movements. The next experimental step uses unfamiliar mechanisms outside the model family and tests camera, proprioceptive and contact observations. Drawing, multi-person inquiry and physical teacher guidance are later experiments.

## Shared interfaces and implementation order

1. **Discovery and provenance.** Keep the original pilot as a regression. Use immutable cue/attempt records from the kernel for observations and read-only scientific telemetry. Give persistent questions a birth-seed-scoped object/individual identifier and time. Keep separate links for support, contradiction, rehearsal and waking outcomes. Add checkpoint serialization with round-trip/restart tests before treating cross-session questions as durable. Compare the current information-gain model with learning-progress, novelty-only, prediction-error and random policies under identical budgets. IAC and expected epistemic value inform sample selection. ICM and RND motivate an explicit random-stimulus stress test. Go-Explore motivates controlled revisits. [Research references](RESEARCH_INTEGRATION.md#curiosity-continuity-and-developmental-benchmarks)
2. **Motor mimicry.** Reuse `PoseFrame`, `PoseTrace`, `PoseMapper` and the learner's own `WalkLearner.Practice`/similarity machinery. The household currently generates parent pose arrays and nudges a child toward observable angles. The older path can compare pose traces. Define a sensory demonstration as immutable time-stamped relative landmarks, contact observations or PCM references plus sensory provenance. The learner holds a private observation target, babbles its own commands against its own body state, compares its resulting sensory trace to the target, and adapts from error. Body correspondence uses normalized relative landmarks and available joints. Learner competence is the independently executed retention probe. A separate outcome score measures emulation. Compare independent exploration, observation-only, observe-and-practice, assisted practice and overnight rehearsal. A later unfamiliar-symbol task scores stroke order, direction, spatial error and smoothness, with assistance withdrawn for transfer. Compare shared observation/execution representation with the simpler pose-error baseline before making claims about mirror-neuron analogs. [Observed visuomotor learning study](https://doi.org/10.1098/rspb.2007.0774)
3. **Instrument and hearing.** Prototype one deterministic, programmatically controlled source–filter instrument in headless C# or behind a versioned native ABI. Pilot two private instances, validated PCM, pitch, articulation and silence. Place it behind a kernel-owned `IVocalInstrument` design taking a tick's motor-control trajectory and respiratory drive and writing PCM to a caller-owned buffer. An `AcousticFrame` design carries tick, sample rate, listener ear, length, and provenance (external, own air path, own conduction, or internal recall). A perception adapter takes only the listener's waveform/features. The study's teacher reference PCM is a sensory target. Commands, weights, transcript and future reference samples stay private. Keep pretrained TTS in a separate teacher/narration service and label all sources. [Dependency options](PHASE_II_DEPENDENCIES.md)
4. **Hearing and vocal imitation.** Keep a continuously updated binaural acoustic field with a quiet mode, explicit ambient sources, path delay, frequency-dependent attenuation and head-relative ITD/ILD. Start with delay and level checks, then calibrate tonal thresholds, a gammatone/ERB filter bank and compression against offline references. Define per-ear thresholds and adaptation explicitly. Low-cost profiles limit band width according to Nyquist. 48 kHz gives 2,400 samples per ear per 0.05-second tick and about 384 kB/s of stereo float samples per learner. Use reusable buffers, and capture raw audio only where the experiment needs it. Human playback consumes the observation asynchronously through Unity. Simulation and phoneme events keep their tick order at every time scale. First compare self- and teacher-generated pitch and vowel-like sounds using F0, envelope, formant and time-aligned trajectory error. Add stochastic surroundings, location and competing sources as separate controls. [Slaney auditory toolbox](https://engineering.purdue.edu/~malcolm/interval/1998-010/)
5. **Respiration and voice health.** Keep anatomy immutable per individual and keep respiratory, vocal motor and health state private. The first respiratory state tracks capacity, lung air, breathing phase, inflow/outflow, pressure, and exertion-driven rate. Integrate bounded air volume from inflow minus outflow at the fixed tick. Phonation consumes air and requires enough pressure. Rest and inhalation run independently of speech. Vocal state tracks fold tension, elasticity, stability, accumulated cycles/load, hydration, irritation and recovery. Integrate a bounded dose from voicing time, F0, estimated effort and hydration. Decay load and recover available pitch with rest. Pressure, fatigue and tract state constrain actual synthesis output. A provisional nonclinical model can scale jitter, roughness and feasible F0 safely. Serialize both states and random phases in a versioned checkpoint. Replay/imagination stores an internal recording or representation and bypasses physical emission, air usage and load. Compare rested, standardized workload and recovery with measured F0, stability and waveform. [Voice-dosimetry research](https://doi.org/10.1044/1092-4388(2003/072))
6. **Integration and observation.** Begin with a real trace viewer, then display synchronized waveforms, spectra and positions. Compare actual teacher and child outputs. Add tract geometry, load and cochlear bands only when the source emits those fields. Record held-out articulation, retention, workload response, and human listening. Add neural rendering only with raw synthesis retained and checks that it preserves timing, articulation, errors and physiological limits. Keep the three libraries, shared/private state boundaries and philosophical mappings in the master [roadmap](DEVELOPMENT_ROADMAP.md).

The completed work is the mechanics and inquiry experiment plus the original latch trace controls. Full motor mimicry, an auditory kernel, individual voice physiology, the Android path and a 3D Neural Observatory remain planned. New dependency distribution and substantial kernel/scene replacements require separate approval.
